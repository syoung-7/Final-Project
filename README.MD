# menu.py

## Project Overview

`menu.py` is a simple Python program created for a programming basics class project. It provides a text-based menu interface that lets the user choose from a set of options and execute basic operations based on that choice.

## How the Program Works

- When the program starts, it displays a menu with numbered choices.
- The user enters a selection using the keyboard.
- The program uses a loop to keep showing the menu until the user chooses to exit.
- Each menu choice is handled with conditional logic to run the appropriate action.
- The program usually includes input validation so invalid selections are handled cleanly.

## Techniques Used

- `while` loop: Keeps the menu active until the user decides to quit.
- `if` / `elif` / `else`: Directs the program flow based on the selected menu option.
- `input()`: Reads user input from the console.
- Functions: Breaks the program into reusable pieces for each menu action.
- Variables: Stores user choices and any data needed for processing.
- Simple error handling: Ensures the program does not crash on unexpected input.

## Running the Program

1. Install Python 3 if it is not already installed.
2. Open a terminal or command prompt.
3. Run the program with:

    python menu.py

4. Follow the on-screen prompts to select menu options.

## Notes

This program is designed to demonstrate basic programming concepts and introduce menu-driven logic in Python. It is intended for learning and practicing fundamental skills such as loops, conditionals, functions, and user interaction.
